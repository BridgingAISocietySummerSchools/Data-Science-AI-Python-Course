# 🚀 Track 2 — Advanced & Self-Learning (self-paced)

The deep-dive track of the course: **ten notebooks, ~6 hours of focused learning** (plus 2–4 hours of practice), taking you from Python fundamentals to training, tuning, and interpreting machine-learning models — and finishing with an end-to-end capstone project.

It is designed for **self-study after the live [Introduction Session](../01_introduction/)** of the [Bridging AI & Society Summer Schools](https://github.com/BridgingAISocietySummerSchools), but works just as well standalone. The first notebooks revisit the introduction-session topics in more depth, so you can start here directly if you missed the session.

## 📓 The notebooks

Work through them **in order** — each notebook assumes you've internalised the previous ones. Every badge opens the notebook in Google Colab with zero setup.

## 🧭 Suggested pace

| Pace | Plan |
|------|------|
| 1 hour / day | 1 notebook per day → done in ~2 weeks |
| 3 hours / weekend | 3 notebooks per weekend → done in ~3 weekends |
| Bootcamp weekend | All 10 in 2 days (~6 hours pure + breaks) |

## 🧪 What's inside each notebook?

1. **Header** — track, time estimate, learning objectives, prerequisites.
2. **Intuition first**, then code, then a brief reflection on the output.
3. **Exercises with complete solutions** (collapsed), including a *"Debug me 🐞"* challenge.
4. **Key takeaways**, a **self-assessment checklist**, and a pointer to the next notebook.
